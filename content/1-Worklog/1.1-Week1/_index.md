### Week 1: Course sprint 1/3 — Cloud foundations, IAM & billing

**Duration:** 11/05/2026 – 17/05/2026

#### Goals

* Complete the first third of the AWS Cloud Journey video curriculum (296 videos in total)
* Build a correct mental model of the cloud before touching the console

#### Work performed

* Watched ~100 videos covering: what cloud computing is, the AWS global infrastructure (Region / Availability Zone / Edge Location), and the shared responsibility model
* IAM in depth: users, groups, roles, policies, the difference between an identity policy and a resource policy, and why the root account must never be used for daily work
* Billing and cost: Free Tier limits, Cost Explorer, Budgets, and the pricing models (On-Demand / Reserved / Spot)
* Kept a running note file mapping every service mentioned to the problem it solves, to be used as the index for the lab weeks

#### Results

* A clear map of the AWS service landscape and the vocabulary to read AWS documentation without getting lost
* Understood the security model well enough to design least-privilege roles later in the project
* A personal note file that became the checklist for weeks 4–10
