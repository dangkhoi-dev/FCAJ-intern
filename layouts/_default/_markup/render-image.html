{{- /* Image render hook. 1) A markdown path such as /images/foo.png is left alone by Hugo when canonifyURLs = false, so on GitHub Pages (site served from https://.github.io//) every image would 404. We strip the leading slash and run it through relURL, which prepends the repo path. relURL - not relLangURL - because static files are shared by both languages and must NOT get a /vi/ prefix. 2) If the file is not in static/ yet, draw a labelled placeholder instead of a broken-image icon. Drop the file in and it becomes a real image; no other edit needed. */ -}} {{- $src := .Destination -}} {{- $alt := .Text -}} {{- if or (hasPrefix $src "http://") (hasPrefix $src "https://") (hasPrefix $src "//") (hasPrefix $src "data:") -}} {{- else -}} {{- $clean := strings.TrimPrefix "/" $src -}} {{- if os.FileExists (printf "static/%s" $clean) -}} {{- else -}} {{ $alt }}
Ảnh sẽ được bổ sung — {{ $src }} {{- end -}} {{- end -}}
